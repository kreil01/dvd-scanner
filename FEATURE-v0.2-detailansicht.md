# v0.2 – Detailansicht aus der Sammlung

- Klick auf eine Kachel öffnet eine reine Leseansicht.
- Klick auf eine Tabellenzeile öffnet dieselbe Detailansicht.
- Die Detailansicht zeigt Cover, Titel, Jahr, Medium, Film/Serie, Genre, Regie, Schauspieler, FSK, Laufzeit, Originaltitel, EAN, Edition, Verlag/Label und Standort.
- `overview` wird bereits unterstützt und automatisch angezeigt, sobald das Feld später in Supabase/TMDb ergänzt wird.
- Bearbeiten erfolgt erst über den separaten Button `Bearbeiten`.
